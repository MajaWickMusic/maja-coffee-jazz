Distributor export

            
Best first source for all 500+ tracks because it can include ISRC, release metadata, artwork, and store availability.

          

          

            
Spotify

            
Good for metadata, album art, previews, popularity, and release mapping. Full audio is not available from the normal public API.

          

          

            
YouTube

            
Useful for matching official videos or topic uploads. Audio extraction should be avoided unless you have a permitted source workflow.

          

          

            
SoundCloud

            
Can work if your account/app has API access or export data. Availability depends on SoundCloud access permissions.
